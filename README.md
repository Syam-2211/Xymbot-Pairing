# 🔗 Getting Your Session ID

Before you can run Xymbot, you need a `session` file so the bot can connect to your WhatsApp account. We have made this incredibly easy with our official Pairing Site!

## 🌐 Quick Link

**👉 Click here to get your code: [Xymbot Pairing Site](https://xymbot-pairing.onrender.com)**

## 📖 Step-by-Step Instructions

1. **Visit the Website:** Open the link above in your web browser.
2. **Enter your Number:** Type in the phone number of the WhatsApp account you want to use for the bot. *(Include your country code, but do not use a `+` sign or spaces. Example: `919876543210`)*.
3. **Get the Code:** Click the **Get Pairing Code** button and wait a few seconds. An 8-digit code will appear on your screen.
4. **Link Your Device:** 
   * Open WhatsApp on your phone.
   * Tap the **three dots** in the top right corner (or Settings on iOS).
   * Tap **Linked Devices** -> **Link a Device**.
   * Tap **Link with phone number instead** at the bottom of the screen.
   * Enter the 8-digit code from the website.
5. **Receive Your Session:** Once linked, wait about 10 seconds. The bot will automatically send a `.zip` file containing your session directly to your WhatsApp!

## 📦 How to Use the Zip File

Once you download the `Xymbot-Session.zip` file from your WhatsApp:
* **For Local/VPS:** Extract the zip file and put all the contents into a folder named `session` inside your bot directory.
* **For Panel/Pterodactyl:** Upload the zip file into your bot's `session` folder and extract it.

> [!WARNING]
> **Keep your session file safe!** Anyone who has this file can control your WhatsApp account. Never share it with anyone.
